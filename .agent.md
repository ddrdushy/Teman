# Teman Testing Agent

This agent helps test the Teman application (multilingual elderly care volunteer platform).

## Test Modes

### 1. Unit Tests
Run component and utility function tests using Vitest.

```bash
pnpm test:unit
```

### 2. Integration Tests
Test API endpoints and database interactions.

```bash
pnpm test:integration
```

### 3. E2E Tests
Full browser testing with Playwright covering user flows.

```bash
pnpm test:e2e
```

### 4. Dev Server Testing
Manual testing against the running dev server at http://localhost:3001

## Core Test Scenarios

### Authentication Flow
- Sign up with phone number
- Verify OTP
- Multilingual sign-in
- Session persistence

### Text Size Control
- Verify 3 text size options work
- Check persistence across reload
- Test in all 4 languages (English, Malay, Tamil, Chinese)

### Language Switching
- Switch between 4 supported languages
- Verify UI updates correctly
- Check persistence across reload

### Volunteer Onboarding
- Profile creation
- Availability scheduling
- Category selection
- Background verification flow

### Matching & Requests
- Create care requests (members)
- Accept volunteer offers
- View matched sessions
- Rate and feedback

## Environment Requirements

- Node.js >= 20
- PostgreSQL 16 with PostGIS
- Environment variables configured in .env
